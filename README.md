# GALLERY BRIDGE

Android-приложение на Kotlin / Jetpack Compose для ручного переноса разрешённых фотографий и видео по HTTPS-ссылке в Google Drive или Mail Cloud (WebDAV).

## Сборка и установка

Основное приложение имеет пакет `com.gallerybridge.app` и поддерживает Android 8.0 и новее. Для сборки нужны JDK 17, Android SDK 36 и Gradle 8.13. Команда проверки — `gradle testDebugUnitTest assembleDebug`.

При отправке изменений в `main` GitHub Actions собирает APK и публикует её в [Releases](https://github.com/vrstk/GALLERY-BRIDGE/releases). Для проверки изменений из pull request существует отдельное приложение **Gallery Bridge Preview**. В запуске Actions скачайте `GalleryBridge-preview-apk`, распакуйте ZIP и установите `app-debug.apk`. Локальная команда сборки preview — `gradle -PgalleryBridgePreview=true assembleDebug`.

Preview устанавливается отдельно и использует собственные настройки и очередь. Опубликованные версии используют отладочные ключи, и установка поверх существующей копии требует совпадения подписей. Для обновлений нужна постоянная подпись.

## Источники и назначения

- Анализ открытых HTTPS-страниц и прямых ссылок на фото и видео. Поддерживаются ссылки в HTML, включая `srcset`, до 300 результатов.
- **Mail WebDAV** использует отдельный пароль приложения. По выбору пользователя пароль сохраняется с шифрованием через Android Keystore.
- **Google Drive API** требует включить Drive API и зарегистрировать Android OAuth-клиент для пакета сборки и SHA-1 её подписи. Приложение запрашивает доступ при начале загрузки.
- **Папка Android / облака** использует системный выбор доступной для записи папки. Передача файла Android-провайдеру и его дальнейшая облачная синхронизация происходят отдельно.
- Одно задание можно выполнять в фоне, останавливать и вручную продолжать оставшиеся файлы. Пропуск существующих файлов основан на их имени. История хранится на устройстве.

## Исправления v0.3 (13 ноября 2026)

- Повтор при временных ошибках DNS, соединения и HTTP 429/5xx для Mail WebDAV с ограниченным ожиданием.
- Если связь с Mail не восстанавливается после двух сетевых сбоев, остановка оставшейся очереди вместо десятков одинаковых ошибок.
- Папки WebDAV готовятся один раз для каждого типа файлов, что снижает количество сетевых запросов.
- Уже существующие файлы пропускаются **до** повторного скачивания.
- Короткий результат загрузки и раскрываемый подробный отчёт на отдельных строках вместо длинного текста с `\\n`.
- Ранее загруженные файлы не удаляются; сравнение содержимого и фоновая очередь запланированы на будущие версии.

**Тестирование:** рекомендуется повторить загрузку тех же 20 фото. Если DNS-ошибка сохраняется, проверить подключение без VPN, с другой сетью и системным DNS. Приложение не может исправить недоступность DNS у оператора самостоятельно.

## v0.4 — передача при сворачивании

- Передача медиа выполняется в отдельной Android foreground-service типа `dataSync`, а не в `MainActivity`.
- Прогресс показывается в системном уведомлении. Можно переключаться между приложениями или выключать экран.
- Есть кнопка остановки, краткий результат и отчёт в приложении после возвращения.
- Пароль Mail и токен Google передаются только во внутреннюю службу, **не сохраняются** в настройках и не публикуются.
- Система может прервать службу при жёстких ограничениях батареи, потере сети, принудительном закрытии/остановке или по лимиту Android 15+.
- При таком прерывании пользователь может повторно начать операцию; уже существующие файлы WebDAV пропускаются. Это пока возобновление **по файлам**, не с середины частично скачанного видео.
- Для гарантированно долгих операций на Android 14+ планируется переход на User-Initiated Data Transfer Job.

### Тест

Установи v0.4, выбери прежнюю галерею и запусти передачу. Сверни приложение, открой другое и проверь уведомление. Затем вернись в GALLERY BRIDGE: счётчик должен продолжать обновляться независимо от экрана. Если передача остановилась, сохрани текст отчёта.

## v0.6 — защищённое сохранение пароля и возобновление очереди

- Рядом с Mail WebDAV добавлен флажок «Запомнить пароль на этом устройстве». По умолчанию пароль не сохраняется.
- При явном выборе и сохранении настроек пароль шифруется ключом AES-GCM из Android Keystore. На диске сохраняются только зашифрованные байты и IV.
- При выключении флажка локально сохранённый пароль и ключ шифрования удаляются.
- Пароль привязан к адресу аккаунта Mail; продолжение очереди другого аккаунта не допускается.
- Для ранее созданных очередей без поля account сохранена обратная совместимость.
- При возобновлении без сохранённого пароля приложение показывает поле для его ввода рядом с очередью. Заново вводить название публикации, дату и ссылку не нужно.
- После удаления приложения или смены телефона пароль необходимо будет ввести повторно. Ключ Android Keystore не переносится.

Сохранение пароля локально — опциональная функция и не означает возобновление в случае принудительного завершения Android без участия пользователя.

## v0.7: очередь по файлам и история

- Три вкладки: Загрузка, Очередь, История.
- Очередь показывает отдельно фактически загруженные, уже существующие в облаке, неудачные и ожидающие файлы.
- Вкладка очереди показывает имя каждого файла и позволяет возобновить только оставшиеся.
- Локальная история сохраняет последние 40 заданий с результатом и временем обновления; повторные попытки одного задания обновляют запись, не дублируют её.
- Отчёт и системное уведомление обновляются по мере окончания обработки отдельных файлов.
- При создании новой загрузки незавершённая сохранённая очередь теперь не перезаписывается. Сначала нужно завершить её. Старые результаты остаются в истории.
- В истории нет паролей, OAuth-токенов и прямых медиа-URL.

Ограничения: одновременно только одна активная очередь; возобновление частично переданного отдельного файла с байта пока не реализовано. История новой версии начнёт пополняться после обновления, старые завершённые задания из версий до v0.7 автоматически не восстанавливаются.

## v0.8 — интерфейс прогресса
- На вкладке «Очередь» теперь виден общий результат: сколько файлов уже в облаке, сколько из них новых, сколько ранее существовало и сколько осталось.
- После начала или возобновления передачи приложение автоматически открывает вкладку «Очередь».
- При переключении вкладок прокрутка возвращается в начало.
- Убран второй (неопределённый) индикатор прогресса поверх индикатора очереди.
- В «Истории» формулировки приведены к единому виду; длинные названия публикаций ограничены двумя строками.
- Исправлено устаревшее сообщение, что пароль Mail не сохраняется: фактически он может сохраняться по выбору пользователя с шифрованием Android Keystore.

Данная версия не добавляет новые методы доступа к сайту или Google OAuth; качество оригиналов на Elite Babes и Google Drive OAuth нужно проверять отдельно.

## v0.9 — папка Android или совместимого облака

- Дополнительное назначение «Папка устройства / облака» через Android Storage Access Framework.
- Если провайдер поддерживает разрешённый выбор папки на запись, приложение создаёт вложенные каталоги модели, фото/видео и публикации.
- Доступ к выбранному каталогу сохраняется между запусками Android с разрешением системы.
- **Google Drive может не показывать выбор папок.** Если он не поддерживает этот механизм, требуется вариант Google Drive API с зарегистрированным OAuth-клиентом.
- Пропуск дубликатов — по имени файла. Для облачного провайдера факт записи не гарантирует мгновенной синхронизации с сервером.
- Работа Mail WebDAV и старые сохранённые очереди остаются без изменений.

## v0.10 — защита от одинаковых папок

На Google Drive была воспроизведена проблема: все 20 уникальных файлов Leona Mia распределились по трем одинаково названным папкам публикации (2 + 2 + 16). Файлы не потеряны, но структура нарушена.

- Сохраняем точные идентификаторы папок SAF, чтобы возобновление не создавало их заново.
- При конфликте одинаковых названий останавливаем создание вместо добавления новых дублей.
- Запрос неуспешного или пустого ответа от провайдера не приравнивается к отсутствию папки.
- Перед созданием папки пишем на диск маркер незавершённого действия. При сбое маркер не позволяет слепо повторить создание.
- Показываем результат по всей очереди, а не только по последней попытке.
- Для Android SAF надпись «передано провайдеру» не означает, что Google Drive закончил серверную синхронизацию.

Существующие дубликаты остаются на месте до отдельной безопасной консолидации. При повторном использовании папки с одинаковыми именами новая версия остановится с понятной ошибкой вместо создания очередной папки.

## v0.11 — безопаснее повторные загрузки

- Для Android SAF файл проверяется на наличие в папке **до повторного скачивания** с исходного сайта.
- Если провайдер показывает файл нулевого размера, приложение сообщает об ошибке и не считает файл готовым.
- При обнаружении дублей файлов или неоднозначных одноимённых папок обработка прекращается до ручной проверки, а не создаёт ещё копии.
- При продолжении сохранённой очереди уведомление показывает **общий прогресс** задания (например, 16/20), а не количество только в последней попытке.
- В фоновой сводке для Android SAF используется формулировка «Передано провайдеру» — это не гарантия серверной синхронизации.

Проверка размера через DocumentsProvider выполняется только если провайдер сообщает размер. Неизвестный или неверно отображаемый размер не доказывает целостность; для настоящего SHA-256 сравнения нужна отдельная проверка обеих сторон.

После ручного объединения каталог Leona Mia подтверждён на Google Drive: один Photo и одна папка публикации, все 20 уникальных имён, суммарно 5 722 535 байт. Эти существующие материалы код не меняет.

## v0.12 — добровольная проверка SHA-256

У завершённой очереди через Android SAF на вкладке «Очередь» появляется кнопка «Проверить SHA-256 и размеры». Приложение читает выбранную папку через доступ DocumentsProvider, повторно получает тот же URL источника по HTTPS и сверяет SHA-256. Также отображает размеры до 6 фотографий в пикселях. При несовпадении и ошибке показывает имена проблемных файлов; файловые операции только на чтение. Лимит для ручной сверки — 32 МиБ на файл; крупные файлы честно пропускаются. Источник может быть недоступен, измениться или возвращать отказ — тогда статус «не проверен».

Ограничение: сверка подтверждает доступные **провайдеру** байты, не гарантирует серверную синхронизацию и не говорит, является ли найденное изображение оригиналом максимального качества. Фоновые загрузки не изменены.

## v0.13 — выбор лучших найденных кандидатов

Сканер дополнительно читает `srcset`, `data-srcset`, `data-full` и `data-original` в открытой HTML-странице. Он не генерирует и не перебирает неподтверждённые URL, а использует только прямые ссылки. При сопоставимых файлах одной галереи кандидат выбирается по указанной ширине в имени или HTML. Автовыбор можно изменить вручную, также можно раскрыть остальные найденные ссылки. Селектор не выполняет платные запросы, не обходит ограничения сайтов и не объявляет версии «оригинальными» без подтверждения.

Результаты работы загрузчика, очередь Mail WebDAV, папка Android/Google Drive и сверка SHA-256 не меняются.

## v0.14 — устранение зависания интерфейса при 300 ссылках

- Исправлен квадратичный пересчёт рекомендаций внутри `items.filter` в Compose.
- Рекомендованные URL рассчитываются один раз после завершения сетевого сканирования, вне главного потока.
- Отображаются только первые 30 строк с кнопкой «Показать ещё», а остальные остаются доступными и не теряются.
- Ручное выделение и кнопка «Выбрать лучшие найденные варианты» работают со всем набором; существующие загрузки/очереди и файлы не изменяются.
- Добавлены тесты для набора из 300 медиассылок.

## v0.15 — проверка реального разрешения до загрузки

- На вкладке «Загрузка» появилась ручная кнопка «Проверить разрешение выбранных фотографий».
- Проверяются только отмеченные фотографии, последовательно, максимум 40 за запуск.
- Приложение читает до 4 МиБ заголовка каждого изображения через HTTPS, распознаёт фактические размеры средствами Android BitmapFactory и показывает результат под именем файла.
- Отдельная кнопка позволяет остановить проверку без отмены фоновых загрузок. Сетевые запросы имеют тайм-ауты, ошибки показываются на конкретных файлах.
- В этой версии результаты проверки информационные и **не меняют автоматически выбор**. Неизвестные или ошибочные размеры так и обозначаются. Нет обещания оригинального качества на сайте.
- Сохранённые очереди, Mail WebDAV, Google Drive, фотографии и история не изменяются.

## v0.16 — сравнение вариантов до загрузки

На вкладке «Загрузка» добавлена команда «Сравнить с другими вариантами». Она формирует не более 20 пар из выбранной фотографии и одной альтернативной ссылки, найденной на той же странице (совпадают CDN-каталог и нормализованная основа имени). Запрашивает реальные размеры через ограниченный HTTPS-ридер версии v0.15, повторно использует успешные измерения текущей сессии и сообщает об альтернативах с большей площадью в пикселях. Поиск новых URL, автоматическая замена, загрузка и удаление файлов **не выполняются**. В случае недоступного кандидата сравнение честно отражает число несопоставленных пар. Это не доказательство наличия или отсутствия иных оригиналов на сайте.

## v0.17 — метаданные страницы

При сканировании Elite Babes приложение предлагает имя модели по типичному началу заголовка публикации. Пустые поля модели/даты могут быть заполнены автоматически, ранее введённые вручную значения не перезаписываются. Дата извлекается лишь из явных метаданных о публикации, структурированных JSON-LD Article/ImageGallery или меток публикации внутри основного блока страницы; при отсутствии подтверждения поле остаётся пустым. Имя модели по заголовку требует проверки пользователем; никакие данные не выдумываются. Существующие очереди и файлы не затрагиваются.

## v0.18 — отдельные данные для каждой галереи

Вставка новой HTTPS-ссылки сбрасывает сведения предыдущей публикации (модель, заголовок, дата, результаты сканирования) и загружает только данные, ранее явно сохранённые пользователем для этой же ссылки. Новая кнопка «Сохранить данные этой галереи» записывает модель, заголовок и реальную дату формата YYYY-MM-DD (либо пустую дату) в локальные настройки с ключом SHA-256 нормализованного URL. Данные не загружаются в GitHub и не отправляются в другие службы. После сканирования сохранённые или введённые вручную поля имеют приоритет над автоматически предложенными значениями. Очереди и уже загруженные файлы остаются без изменений.
