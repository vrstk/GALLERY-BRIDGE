# GALLERY BRIDGE

Android-приложение на Kotlin / Jetpack Compose для ручного переноса разрешённых фотографий и видео по HTTPS-ссылке в Google Drive или Mail Cloud (WebDAV).

## Текущий статус

**v0.2 — экспериментальный MVP.** Сборка запускается GitHub Actions автоматически после коммита в `main`. Возможность доступа к конкретным сайтам, включая Elite Babes, не подтверждена.

## Что есть

- Поле HTTPS-ссылки на страницу или прямой медиафайл.
- Поиск ссылок на JPG, PNG, WebP и MP4/WebM в статическом HTML.
- Выбор файлов перед передачей; ссылки на миниатюры не считаются подтверждёнными оригиналами.
- Создание папок `♀️ Модель / 📷 Photo` либо `🎬 Video / 🍓 Дата — Название`.
- Один пункт назначения за операцию: Mail WebDAV или Google Drive.
- Пропуск файлов с уже существующим именем; сохранение основных настроек (не пароля).

## Как скачать APK

Перейдите в **Actions → Build Android APK**. После зелёного результата откройте запуск и скачайте **GalleryBridge-debug-apk** из Artifacts. Распакуйте ZIP и установите `app-debug.apk`. В случае ошибки смотрите лог сборки.

## Mail WebDAV

Используется `https://webdav.cloud.mail.ru/`. Потребуются логин Mail и отдельный пароль внешнего приложения. В текущей версии пароль вводится заново после перезапуска приложения.

`1vWsFWxllS6aOh6a0iD58w30moPHiDP4T`.

Google OAuth **не заработает без настройки Google Cloud**: включите Drive API и создайте Android OAuth client для package `com.gallerybridge.app` с SHA-1 подписи установленного APK. Текущая экспериментальная интеграция запрашивает scope `drive`, который требует повышенного доступа и для публичного приложения может потребовать проверки Google. Позже лучше заменить выбор папки на Google Picker и ограничить разрешения.

## Ограничения

- Нет гарантии доступа к Elite Babes. Автоматическая загрузка защищённых галерей, видео HLS/DASH, DRM и обход Cloudflare не поддерживаются.
- Нет фоновой очереди, продолжения частичной загрузки, проверок SHA-256 и массовой автоматизации.
- Приложение должно оставаться открытым во время передачи.
- Программа пока не проверена на реальном Android-устройстве и с реальными облаками.
- Временные файлы хранятся в `cacheDir` и удаляются по завершении операции.
- Не размещайте пароли или OAuth-токены в публичном репозитории.

## Изменения v0.2

- Корректное отображение с отступами от системных панелей Android.
- Путь Mail `Images/xxx/` создаёт **две** вложенные папки вместо одной.
- По умолчанию выделяются ссылки на медиа, а дополнительные изображения/миниатюры скрыты.
- Отчёт о причинах ошибок загрузки показывает HTTP-статус или другую причину для каждого проблемного файла.
- Ошибка `UNREGISTERED_ON_API_CONSOLE` поясняется как отсутствие зарегистрированного OAuth-клиента.

Ранее сохранённые файлы в Облаке Mail не удаляются и не перемещаются. При повторной загрузке сравнение дубликатов пока работает по имени.

## Исправления v0.3 (13 ноября 2026)

- Повтор при временных ошибках DNS, соединения и HTTP 429/5xx для Mail WebDAV с ограниченным ожиданием.
- Если связь с Mail не восстанавливается после двух сетевых сбоев, остановка оставшейся очереди вместо десятков одинаковых ошибок.
- Папки WebDAV готовятся один раз для каждого типа файлов, что снижает количество сетевых запросов.
- Уже существующие файлы пропускаются **до** повторного скачивания.
- Короткий результат загрузки и раскрываемый подробный отчёт на отдельных строках вместо длинного текста с `\\n`.
- Ранее загруженные файлы не удаляются; сравнение содержимого и фоновая очередь запланированы на будущие версии.

**Тестирование:** рекомендуется повторить загрузку тех же 20 фото. Если DNS-ошибка сохраняется, проверить подключение без VPN, с другой сетью и системным DNS. Приложение не может исправить недоступность DNS у оператора самостоятельно.

## v0.4 — передача при сворачивании

- Передача медиа выполняется в отдельной Android foreground-service типа `dataSync`, а не в `MainActivity`.
- Прогресс показывается в системном уведомлении. Можно переключаться между приложениями или выключать экран.
- Есть кнопка остановки, краткий результат и отчёт в приложении после возвращения.
- Пароль Mail и токен Google передаются только во внутреннюю службу, **не сохраняются** в настройках и не публикуются.
- Система может прервать службу при жёстких ограничениях батареи, потере сети, принудительном закрытии/остановке или по лимиту Android 15+.
- При таком прерывании пользователь может повторно начать операцию; уже существующие файлы WebDAV пропускаются. Это пока возобновление **по файлам**, не с середины частично скачанного видео.
- Для гарантированно долгих операций на Android 14+ планируется переход на User-Initiated Data Transfer Job.

### Тест

Установи v0.4, выбери прежнюю галерею и запусти передачу. Сверни приложение, открой другое и проверь уведомление. Затем вернись в GALLERY BRIDGE: счётчик должен продолжать обновляться независимо от экрана. Если передача остановилась, сохрани текст отчёта.
