# Матрица тестирования GALLERY BRIDGE

Фиксируйте версию, SHA, Android, провайдер и результат. Для каждого облачного сценария используйте отдельные тестовые файлы и папки.

| Область | Автоматическая проверка | Проверка на телефоне перед Stable |
| --- | --- | --- |
| APK и обновление | Debug и release unit-тесты, Android UI, проверка пакета, сертификата и SHA-256, чистая установка и `install -r` на Android 15, сверка заполненных записей каталога, истории, очереди, журнала SHA-256 и настроек (включая отключённую автопроверку обновлений) до установки, после неё и после первого запуска, включая восстановление флага прерванной передачи | Проверка обновления из приложения, загрузка, отказ в разрешении установки и повтор, системное подтверждение установки, сохранение каталога, истории, темы, очереди и разрешения SAF |
| Каталог и копия | Тесты каталога, импорта и экспорта, ошибок данных, поиска, пакетных операций и навигации | Большая коллекция, повторный импорт, ручные метаданные, прерванное сканирование, сохранение позиции и выделения при навигации и повороте |
| Изображения и UI | Android UI для заглавного экрана, навигации, тем, выбора, просмотра и повтора загрузки | Обе темы, системная кнопка «Назад», управление одной рукой, масштабирование, свайп, ошибка и повтор миниатюры |
| Очередь | Тесты переходов состояний, контрольных точек, повторов, защиты от дублей и непроверенных записей | Сворачивание, выключение экрана, обрыв и смена сети, остановка процесса, затем возобновление и сверка без дублей |
| Mail WebDAV и Android SAF | Тесты политик записи, привязки к назначению, проверок файлов и отчётности | Копирование в обе системы, большое задание, закрытие очереди, частичный файл, запрещённая папка, совпадающее имя с разным содержимым |
| Целостность | Контроль размеров, SHA-256 и фиксации результата передачи | Сверка известного файла с источником, затем отдельное подтверждение появления в удалённом облаке через внешний клиент |

## Приёмка кандидата 0.99.6 (RC)

Номер версии остаётся числовым для совместимости со встроенным обновлятором. Это Signed Preview, а не Stable. Сборка содержит тот же прикладной код, что 0.99.5, с усиленной автоматической проверкой запуска: явный запуск MainActivity и контроль неизменного PID через 5 секунд на чистой установке и после обновления.

Пользователь подтвердил общую работоспособность предыдущей версии. Отдельные сценарии ниже пока не подтверждены. Использовать отдельные тестовые папки, не удалять приложение и не очищать его данные.

- [ ] Обновить 0.99.5 до 0.99.6 из настроек, убедиться в сохранности каталога, истории, очереди, темы и доступов SAF.
- [ ] Проверить отказ в разрешении установки и повторную установку через системный диалог, если разрешение можно безопасно отозвать для этого теста.
- [ ] Передать несколько разрешённых тестовых фотографий в Mail WebDAV и системную папку, проверить файлы во внешнем клиенте и повтор без дублей.
- [ ] На тестовом задании свернуть приложение, отключить и восстановить сеть, проверить возобновление и отсутствие повторной записи подтверждённых файлов.
- [ ] Проверить каталог, резервную копию (экспорт; повторный импорт только на тестовых данных), просмотр, навигацию и обе темы.
- [ ] Зафиксировать результаты полной матрицы выше, включая большие списки и ошибки провайдера.

Критерий Stable: успешный CI кандидата, подтверждённая подписанная публикация и пройденная телефонная матрица. Любой дефект сохранности данных блокирует выпуск. Слияние main — только по отдельному согласованию.
