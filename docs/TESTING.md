## Приёмка кандидата 0.99.6 (RC)

Номер версии остаётся числовым для совместимости со встроенным обновлятором. Это Signed Preview, а не Stable. Сборка содержит тот же прикладной код, что 0.99.5, с усиленной автоматической проверкой запуска: явный запуск MainActivity и контроль неизменного PID через 5 секунд на чистой установке и после обновления.

Ниже — исходный план приёмки RC. Фактически полученные результаты по двум пользовательским спискам приведены в протоколе от 27.11.2026. Использовать отдельные тестовые папки, не удалять приложение и не очищать его данные.

- [ ] Обновить 0.99.5 до 0.99.6 из настроек, убедиться в сохранности каталога, истории, очереди, темы и доступов SAF.
- [ ] Проверить отказ в разрешении установки и повторную установку через системный диалог, если разрешение можно безопасно отозвать для этого теста.
- [ ] Передать несколько разрешённых тестовых фотографий в Mail WebDAV и системную папку, проверить файлы во внешнем клиенте и повтор без дублей.
- [ ] На тестовом задании свернуть приложение, отключить и восстановить сеть, проверить возобновление и отсутствие повторной записи подтверждённых файлов.
- [ ] Проверить каталог, резервную копию (экспорт; повторный импорт только на тестовых данных), просмотр, навигацию и обе темы.
- [ ] Зафиксировать результаты полной матрицы выше, включая большие списки и ошибки провайдера.

Критерий Stable: успешный CI кандидата, подтверждённая подписанная публикация и пройденная телефонная матрица. Любой дефект сохранности данных блокирует выпуск. Слияние main — только по отдельному согласованию.
