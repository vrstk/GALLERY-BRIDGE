# Матрица тестирования GALLERY BRIDGE

Фиксируйте версию, SHA, Android, провайдер и результат. Для каждого облачного сценария используйте отдельные тестовые файлы и папки.

| Область | Автоматическая проверка | Проверка на телефоне перед Stable |
| --- | --- | --- |
| APK и обновление | Debug и release unit-тесты, Android UI, проверка пакета, сертификата и SHA-256, чистая установка и `install -r` на Android 15, сверка заполненных записей каталога, истории, очереди и настроек до установки, после неё и после первого запуска | Проверка обновления из приложения, загрузка, отказ в разрешении установки и повтор, системное подтверждение установки, сохранение каталога, истории, темы, очереди и разрешения SAF |
| Каталог и копия | Тесты каталога, импорта и экспорта, ошибок данных, поиска, пакетных операций и навигации | Большая коллекция, повторный импорт, ручные метаданные, прерванное сканирование, сохранение позиции и выделения при навигации и повороте |
| Изображения и UI | Android UI для заглавного экрана, навигации, тем, выбора, просмотра и повтора загрузки | Обе темы, системная кнопка «Назад», управление одной рукой, масштабирование, свайп, ошибка и повтор миниатюры |
| Очередь | Тесты переходов состояний, контрольных точек, повторов, защиты от дублей и непроверенных записей | Сворачивание, выключение экрана, обрыв и смена сети, остановка процесса, затем возобновление и сверка без дублей |
| Mail WebDAV и Android SAF | Тесты политик записи, привязки к назначению, проверок файлов и отчётности | Копирование в обе системы, большое задание, закрытие очереди, частичный файл, запрещённая папка, совпадающее имя с разным содержимым |
| Целостность | Контроль размеров, SHA-256 и фиксации результата передачи | Сверка известного файла с источником, затем отдельное подтверждение появления в удалённом облаке через внешний клиент |
