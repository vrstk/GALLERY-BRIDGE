# GALLERY BRIDGE: постоянная подпись Preview APK

Начиная с 0.31, публикация **требует** постоянного ключа подписи. Это исключает повторение ошибки «недействительный пакет» при установке обновлений, вызванной сменой сертификата.

## 1. Настройка GitHub Secrets (один раз)

Откройте https://github.com/vrstk/GALLERY-BRIDGE/settings/secrets/actions и создайте четыре Repository secrets:

1. `GALLERY_BRIDGE_PREVIEW_KEYSTORE_B64` — Base64 всей приватной JKS/PKCS12-подписи (одна строка).
2. `GALLERY_BRIDGE_PREVIEW_STORE_PASSWORD` — пароль хранилища.
3. `GALLERY_BRIDGE_PREVIEW_KEY_ALIAS` — имя ключа.
4. `GALLERY_BRIDGE_PREVIEW_KEY_PASSWORD` — пароль ключа.

Для этого проекта создан личный комплект подписи вне репозитория. Используйте точные значения из его `GitHub_Secrets.txt`. **Не добавляйте приватный ключ или этот файл в Git.** Храните архив в личном защищённом месте и сделайте отдельную офлайн-копию.

Публичный SHA-256 отпечаток сертификата, закреплённый в GitHub Actions: `06f59535fa8cb13507a2d77305daed1b81016459bc5884b5d837c3823f9664a1`.

## 2. Выпуск проверенной APK

Откройте https://github.com/vrstk/GALLERY-BRIDGE/actions/workflows/android.yml, выберите Run workflow и ветку `codex/gallery-bridge-home`. При наличии всех четырёх секретов Actions проверит отпечаток сертификата, установку на Android-эмулятор и опубликует релиз `preview-signed`.

Скачать APK: https://github.com/vrstk/GALLERY-BRIDGE/releases/tag/preview-signed

Если сертификат отсутствует или не совпадает, **сборка остановится и не заменит ранее опубликованную APK**. Изменение одного из четырёх секретов или создание нового ключа в будущем разрушит совместимость обновлений.

## 3. Перенос старых данных

Версия 0.30 Recovery имеет пакет `com.gallerybridge.app.preview.recovery`; начиная с 0.31 подписанный Preview использует `com.gallerybridge.app.preview.signed`.

Оба приложения можно держать одновременно. В старой версии 0.30 откройте «Каталог галерей» → «Сохранить копию», сохраните JSON в доступную папку. Затем установите подписанный Preview, откройте «Каталог галерей» → «Восстановить» и выберите файл. Проверяйте счётчики и названия до удаления старого приложения.

JSON включает **каталог, последние 40 записей истории и тему**, но не переносит файлы, пароли, активную очередь и разрешения папки Android. Облачные назначения настройте самостоятельно.

Не удаляйте старую версию до завершения экспорта и проверки восстановления данных.
