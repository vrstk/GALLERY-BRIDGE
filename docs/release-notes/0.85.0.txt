0.85.0 — исправлена read-only SHA-256 проверка завершённых пакетных передач: для каждого файла проверяется именно папка исходной галереи (в том числе при совпадающих именах файлов), а не общая папка всей очереди. Путь проверки берётся из QueueStore.foldersFor — того же правила, что используется при загрузке. Ранее сохранённые очереди без SHA-256, вычисленного во время передачи, честно отмечаются неподтверждёнными: повторно скачанный источник не выдаётся за доказательство целостности старых байтов. Проверка не создаёт папки, не перезаписывает данные и не меняет очередь. Добавлены unit-тесты путей одиночной и пакетной очереди, старых хешей и отчёта. Подписанный package ID, SAF, Mail WebDAV, история и каталог сохранены.\n
