GALLERY BRIDGE 0.63.0 — исправление навигации по скриншотам

— Исправлена иконка вкладки «Галереи»: вместо залитого светлого квадрата используется отдельный прозрачный контурный значок фотографии.
— В горизонтальной ориентации нижняя навигация стала компактной: 52 dp для четырёх вкладок вместо высокой панели Material 3.
— Верхняя панель в горизонтальной ориентации также стала ниже, чтобы сохранить место фотографиям.
— В вертикальной ориентации сохранён привычный вид нижней панели и русские названия разделов.
— Кнопки очереди и истории, действия с выбранными фотографиями, SAF и WebDAV сохраняют своё поведение.
— Добавлен инструментальный Compose UI-тест компактной компоновки и навигации, без доступа к пользовательским данным или сетевым источникам.
