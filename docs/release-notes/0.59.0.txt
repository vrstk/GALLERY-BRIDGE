GALLERY BRIDGE 0.59.0 — Photo First / compact UI

— Убрана слишком крупная синяя заливка кнопок выбора на фото: видимый индикатор уменьшен до 26 dp, прозрачная зона нажатия остаётся 44 dp.
— Компактнее главный экран: без повторяющихся пояснений, с более короткими карточками хранилищ и читаемой иконкой каталога.
— Каталог: сокращены визуальные плашки и отступы; действия «Изменить» и «Убрать» перенесены в меню публикации, подтверждение удаления сохранено.
— Очередь: меньше повторяющихся счётчиков, компактный список и корректная полоса прогресса без маркера на 100%; подсказка о HTTP 403 появляется только при соответствующей ошибке.
— История: компактные строки и дата в заголовке карточки; значения истории, очереди и статус облачной синхронизации не изменяются.
— Критически важные операции (SAF, Mail WebDAV, сохранение очереди, интеграция обновлений) не изменены.
— Добавлены UI-регрессии для размера видимого индикатора и подтверждения опасного действия.
