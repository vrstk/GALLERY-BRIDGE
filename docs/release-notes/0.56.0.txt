GALLERY BRIDGE 0.56.0

— Повторные попытки скачивания APK продолжают сохранённый частичный файл по строгому HTTP Content-Range.
— Добавлены тесты прерывания потока, возобновления, сохранения SHA-256, игнорирования Range сервером, неверных диапазонов и отмены.
— После отмены или замены задачи удаляются только бесхозные файлы загрузки обновлений. Проверенная verified.apk не удаляется очисткой.
— Запись временной APK вынесена в отдельный проверяемый компонент, проверяющий размер и смещение перед записью.
— По-прежнему используется системное подтверждение установки, проверка package ID, сертификата, SHA-256 и versionCode.
— Данные галерей, история, настройки, SAF, WebDAV и очередь загрузок фотографий не затронуты.
