0.83.0 — массовая загрузка фотогалерей разделена на проверку и явное подтверждение. До создания очереди показываются доступные фотографии, недоступные публикации и потенциальные повторы. Отмена не изменяет существующую очередь. При подтверждении повторно проверяются назначение, сохранённая очередь и журнал обработанных фотографий. Пакетный журнал теперь связывает записи с конкретными публикациями, чтобы не потерять сведения о прежних передачах. Добавлены тесты предпросмотра и защиты от повторов. Сохранены подпись, package ID и пользовательские файлы.
