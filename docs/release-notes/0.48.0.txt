GALLERY BRIDGE 0.48.0
— Упрощён каталог: единая прокрутка от поиска до последней карточки, фильтры, пакетные инструменты и резервное копирование раскрываются по запросу.
— Убран импорт MHT из пользовательского интерфейса; существующий каталог и архивы не удаляются.
— Галерея отображается только мозаикой, включая установки с ранее выбранными режимами «Плитка» и «Список».
— При повороте экрана результаты поиска, выделения, текущая галерея и загрузка обновления сохраняются в ViewModel, без перезапуска задания.
— Поддерживаются ссылки на страницу модели без обязательного sort/oldest; число доступных страниц HTML-пагинации увеличено до 100. Динамические карточки, недоступные в HTML, по-прежнему явно обозначаются как неполный список.
