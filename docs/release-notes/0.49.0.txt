GALLERY BRIDGE 0.49.0
— Поиск фотопубликаций модели перенесён в WorkManager: он может продолжаться при сворачивании и блокировке экрана, а после перезапуска восстанавливает обработанные HTML-страницы.
— После каждой проверенной страницы сохраняется контрольная точка; найденные публикации не подменяются миниатюрами и не запускают передачу автоматически.
— Расширен последовательный поиск по пагинации, которую сам сайт показал в HTML. При отсутствии доступа к динамическим публикациям приложение сообщает о неполном результате; гарантировать все галереи сайт пока не позволяет.
— Фотографии, выбранные файлы и текущий экран сохраняются в приватном файле при уходе приложения в фон и восстанавливаются после пересоздания процесса.
— Менеджер обновлений сохраняет проверенный манифест и повторно проверяет ранее скачанный APK при новом запуске. Активную загрузку APK после принудительного завершения процесса потребуется повторить.
