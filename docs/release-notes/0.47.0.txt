Добавлен безопасный импорт HTML-части сохранённых MHT/MHTML-снимков каталога модели через системный выбор до 10 файлов. Встроенные изображения и видео не читаются, JavaScript не запускается.
Снимки страниц одной модели объединяются по номеру страницы; при повторном импорте выбирается снимок с большим количеством карточек. Отсутствующие страницы отмечаются в отчёте, видеокарточки не добавляются в список фотопубликаций.
Публикации можно просматривать и вручную сохранять в существующий каталог. Текущая очередь, история, облачные файлы, настройки и подпись не изменяются.
Полная автоматическая подгрузка карточек сайта пока недоступна без проверенного описания штатного механизма загрузки.
