Добавлен локальный журнал результатов отдельных фотографий: хранит только хешированные признаки имён и статусы обработки, без медиа-URL и данных авторизации.
При повторной передаче той же публикации в то же назначение приложение показывает совпадения и позволяет передавать только фотографии без отметок о предыдущей обработке.
Подтверждённые состояния очереди сохраняются перед её заменой или закрытием. Совпадение имени не доказывает целостность файла либо завершение облачной синхронизации.
