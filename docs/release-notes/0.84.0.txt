0.84.0 — точные статусы фотогалерей и фильтры каталога. Единая пакетная очередь связывается отдельно с каждой публикацией по канонической ссылке: ошибки FAILED, требующие ручной проверки BLOCKED, ожидание и результаты DONE/SKIPPED больше не смешиваются между разными галереями. Добавлены фильтры «Без передач», «Передавались», «В очереди», «Требуют внимания», «Ошибки». Сортировка по времени называется «Недавно добавлены», чтобы не путать её с фильтром новых записей. Сообщения не утверждают, что облачная синхронизация подтверждена, если есть только локальный checkpoint. Статусы и фильтры вычисляются в памяти: очередь, каталог, история, данные, подпись и назначения не перезаписываются. Добавлены unit-тесты смешанных и больших очередей и инструментальная проверка фильтров.
