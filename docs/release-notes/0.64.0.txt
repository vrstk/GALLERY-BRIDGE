GALLERY BRIDGE 0.64.0 — ручной ввод даты без лишних ошибок

— Поле даты в данных фотопубликации и окне редактирования каталога принимает восемь цифр и автоматически вставляет разделители: 20250829 → 2025-08-29.
— Для даты открывается цифровая клавиатура. Поддерживаются вставка полной даты и исправление ввода; длина ограничена восьмью цифрами.
— Неполные даты и календарно невозможные значения не сохраняются. Пустая дата по-прежнему допускается.
— Хранение даты остаётся прежним (ISO 8601: ГГГГ-ММ-ДД), поэтому каталог, история и резервные копии не мигрируют.
— Добавлены unit-тесты маски и Android UI-тесты ввода и ошибок.
— Подпись, package ID, SAF, Mail WebDAV, очереди, скачивание и безопасный менеджер обновлений не изменены.
