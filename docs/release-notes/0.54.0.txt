GALLERY BRIDGE 0.54.0

— Восстановление открытого полноэкранного фото и текущего положения просмотра при повороте Android.
— Избранные фотографии и метаданные остаются в приватной контрольной точке, без хранения паролей, ключей и самих фото.
— После холодного старта сохранённый просмотр восстанавливается по явному выбору пользователя.
— Инструментальный тест корректно ожидает завершения асинхронного открытия Dialog после пересоздания Activity, исключая гонку проверки интерфейса.
— Подпись, идентификатор пакета, очередь, настройки, каталог и хранилища неизменны.
