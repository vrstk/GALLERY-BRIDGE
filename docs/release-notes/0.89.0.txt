Пакетный просмотр добавляет публикации из текущего списка с учётом поиска, фильтров и выбранной модели. Ранее выбранные публикации сохраняются; видно, сколько из них вне списка. Перед запуском показаны названия публикаций в порядке просмотра. Галереи из сохранённой очереди исключены, включая пакетные передачи.
