GALLERY BRIDGE 0.67.0 — выборочный безопасный повтор ошибок

— В сохранённой очереди у фотографий со статусом FAILED появилась команда «Повторить только этот файл» с отдельным подтверждением.
— При выборочном повторе обрабатывается только точный индекс записи исходной очереди. Остальные ожидающие, загруженные, пропущенные и заблокированные файлы не передаются повторно.
— Сервис проверяет ID очереди и её актуальное состояние перед повтором; после изменения очереди старый запрос не выполняется.
— Записи BLOCKED по-прежнему требуют ручной проверки; видео из старых очередей не запускаются.
— Причина ошибки сохраняется до успешного результата; существующий общий режим продолжения остаётся без изменений.
— Добавлены unit-тесты безопасного выбора записей и Android UI-тест подтверждения/отмены без сетевых запросов.
— Каталог, история, настройки, Android SAF, Mail WebDAV, пакет и сертификат подписи не изменены.
