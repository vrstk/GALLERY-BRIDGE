0.73.0 — уточнён поиск исходных фотографий на страницах публикаций: поддержка явно связанных изображений Fancybox (data-fancybox=images, data-fancybox-group, data-src и legacy class=fancy внутри статьи). Миниатюры, обложки и рекламные ссылки не включаются в очередь, выдуманных CDN-адресов нет. Добавлены unit-тесты новых вариантов HTML и отказа от неподтверждённых медиа. Проверка завершения списка модели остаётся строгой: совпадение 432 карточек с числом на сайте без ответа API не считается доказательством полного списка.
