GALLERY BRIDGE 0.68.0 — проверка сохранённых байтов SAF и Mail WebDAV

— В завершённой очереди появилась ручная проверка SHA-256 для обоих поддерживаемых назначений: Android SAF и Mail WebDAV.
— Проверка только читает файлы, не создаёт папки, не перезаписывает фотографии, не меняет очередь и историю.
— Для свежих очередей используется уже сохранённый SHA-256 исходных байтов. Если хеша нет в старом задании, исходник скачивается повторно; отсутствие доступа отображается как непроверенный файл.
— Mail WebDAV проверяется через Depth: 0 PROPFIND и GET по закреплённому HTTPS-адресу; редиректы с учётными данными запрещены. Размер из PROPFIND сверяется с прочитанными байтами.
— Для Mail требуется пароль приложения и исходный аккаунт очереди. Пароль не записывается в отчёт или очередь.
— Результаты разделяют «принято по очереди», «проверено по содержимому», отличия и недоступные для проверки файлы.
— Для Android SAF чтение провайдером не считается доказательством завершения удалённой синхронизации. Для Mail подтверждаются доступные для чтения байты, не долговременное хранение.
— Ограничение ручной проверки: 32 МиБ на файл; изменения больших фотографий не предполагаются без явного подтверждения.
— Добавлены unit-тесты политики хеширования/учётной записи и инструментальный тест UI завершённой очереди Mail.
— Сохранены package ID, сертификат, каталоги, история, настройки, очередь, WebDAV и SAF без миграции данных.
