Для новых результатов передачи фотографий сохраняется SHA-256 исходных байтов вместе с прежней записью об обработке. Старые очереди и журналы без хеша продолжают читаться без миграции и удаления.
При проверке уже существующего файла SHA-256 подтверждается сравнением байтов источника и назначения. Если файл появился в папке Android во время загрузки, пропуск разрешён только после повторной проверки.
Хеш исходника сам по себе не означает, что облачный провайдер завершил синхронизацию. Автоматическое удаление или перезапись файлов не добавлены.
