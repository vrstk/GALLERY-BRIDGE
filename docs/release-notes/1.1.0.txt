Первый этап развития архитектуры источников. Введена общая политика разрешённых HTTPS-адресов для существующего адаптера, отклоняются встроенные учётные данные, неоднозначные параметры API и номера страниц вне диапазона. Добавлены регрессионные тесты. Новые домены пока не подключены; очереди, хранилища и формат данных не изменены.
