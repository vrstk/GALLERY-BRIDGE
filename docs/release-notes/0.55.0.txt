GALLERY BRIDGE 0.55.0

— Скачивание подписанных обновлений выполняет WorkManager, независимо от Activity.
— Передача APK сохраняет частично полученные байты в приватном каталоге и возобновляется с HTTP Range после системного перезапуска задачи.
— Если сервер не поддерживает Range и возвращает 200 OK, частичный файл заменяется полной загрузкой вместо недопустимого дописывания.
— Ответ 206 принимается только при точном Content-Range и совпадении заявленного размера.
— Сохраняются проверка SHA-256, package ID, версии и закреплённого сертификата перед выдачей APK системному установщику.
— Есть прогресс, отмена из интерфейса и уведомления, повтор при временной сетевой ошибке; установка только после отдельного действия пользователя.
— Ранее скачанный APK повторно проверяется при старте, обновление не прерывает передаваемые фотографии.
— Подпись, applicationId, очередь, каталог, история, WebDAV и Android SAF не изменены.
