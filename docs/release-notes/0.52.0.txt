GALLERY BRIDGE 0.52.0

— Полноэкранный просмотр фотографий без места, отведённого под шапку и нижнюю панель.
— Компактные прозрачные элементы управления поверх фото, скрываются/появляются после одного касания.
— Двойное нажатие увеличивает фотографию до заполнения экрана; повторное сбрасывает масштаб.
— Pinch-to-zoom до 6×, перемещение увеличенного фото, свайпы между фотографиями при масштабе 1×.
— Сохранение открытого изображения и масштаба при обычном пересоздании Activity.
— Исправлена надёжность UI-теста: одиночное касание подтверждается после таймаута распознавания двойного.
— Защита выпуска: CI теперь требует успешные Android UI-тесты именно для push-релиза. Если тесты падают, новая подписанная APK не публикуется.
— Сохранены пользовательские данные, очередь, каталог, WebDAV/SAF, package ID и сертификат.
