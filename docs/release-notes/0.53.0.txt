GALLERY BRIDGE 0.53.0

— Во время просмотра полноэкранных фотографий сохраняется URL текущего изображения при перелистывании.
— Открытая фотография остаётся доступной после поворота и обычного пересоздания Activity.
— После завершения процесса Android восстановление предыдущего просмотра доступно через явную кнопку на главном экране.
— Снимок сессии содержит только URL фотографий и метаданные, не содержит паролей, токенов или самих изображений.
— Старые снимки сессии остаются совместимыми: отсутствующее поле открытой фотографии безопасно игнорируется.
— Добавлены unit- и Android UI-тесты восстановления просмотра.
— Подпись, package ID, каталог, история, очередь и хранилища не изменены.
